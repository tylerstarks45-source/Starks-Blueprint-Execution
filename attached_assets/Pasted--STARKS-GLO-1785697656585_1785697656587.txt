═══════════════════════════════════════════════════════════════════════
PURPOSE
═══════════════════════════════════════════════════════════════════════

The Unified Builder Runtime Engine provides the execution runtime
for every visual builder inside the platform.

Builders do not implement runtime behavior.

Builders declare editing capabilities.

UBRE provides the runtime.

Every future builder inherits:

• editing sessions

• autosave

• validation

• undo

• redo

• draft state

• preview state

• publishing state

• collaboration state

• runtime events

• locking

• change history

• builder lifecycle
