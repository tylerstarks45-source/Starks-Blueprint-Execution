# Command-center protocol (v1)

HTTP contract for the 3D web command center and the Unreal client. Every
response carries `protocol: 1`; breaking changes bump it.

## Auth

Either header works:

- `Authorization: Bearer <JWT>` from `POST /api/auth/login`.
- `X-API-Key: <key>` from the API-key settings page (best for Unreal).

All data is scoped to that user. Other users' businesses are never returned.

## `GET /api/command-center/context`

Scene snapshot. Poll it when the scene loads and after each turn.

```json
{
  "protocol": 1,
  "generatedAt": "2026-11-11T15:00:00.000Z",
  "businesses": [{ "id": 12, "name": "Own Shop", "businessType": "ecommerce", "status": "active" }],
  "portfolio": { "...": "same shape as GET /api/business-intelligence/summary" }
}
```

## `POST /api/command-center/turn`

One ASH turn. ASH uses its tools (business context, portfolio, research,
learned patterns) before answering. The avatar should only say `spokenText`.

Request:

```json
{
  "message": "How are my businesses doing?",
  "history": [{ "role": "user", "content": "..." }, { "role": "assistant", "content": "..." }],
  "mode": "business",
  "speak": true,
  "voice": "onyx"
}
```

- `history`: up to 20 earlier messages. The client keeps the conversation.
- `mode`: `fast`, `business`, `expert` or `empire`. Lowered to what the user's plan allows.
- `voice`: `alloy`, `ash`, `coral`, `echo`, `fable`, `nova`, `onyx` (default), `sage`, `shimmer`. Speech is generated by Deepgram Aura-2 through OpenRouter; each name maps to an Aura-2 voice (`onyx` → `aura-2-orion-en`, see `AURA_VOICES` in `lib/openrouter-media.ts`).

Response:

```json
{
  "protocol": 1,
  "text": "Markdown answer for on-screen display",
  "spokenText": "Same answer as plain text",
  "speech": { "audioBase64": "<mp3>", "mimeType": "audio/mpeg", "voice": "onyx" },
  "speechError": null,
  "actions": [{ "type": "image", "prompt": "..." }],
  "steps": [{ "tool": "get_portfolio_summary", "ok": true }],
  "model": "anthropic/claude-3-5-sonnet"
}
```

- `speech` is `null` when `speak` is false or voice generation failed. `speechError` is then `"out_of_credits"` or `"unavailable"`, and the client should show `text` as a caption.
- `actions` are the workspace actions ASH asked for, in the web app's `tool_calls` format. A 3D client can show them or hand them to the web app.
- Errors: `400` invalid body, `401` not logged in, `402` out of credits, `502` ASH unavailable.

Speech goes through OpenRouter (`/audio/speech`) and is billed like every other AI call.
For lip sync, run the mp3 through the client's own viseme generator (e.g. Unreal MetaHuman audio-to-face).
