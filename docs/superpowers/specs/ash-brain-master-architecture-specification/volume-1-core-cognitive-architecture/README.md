# Volume 1 — Core Cognitive Architecture

**Status:** Framework established. No chapter has entered the Architecture phase yet.

## Purpose

The reasoning and planning layers that sit between a user request and any model call or side effect: how ASH decides what a request is about, plans how to act on it, validates the plan, remembers relevant context, and grounds itself in real outcomes rather than model guesswork.
