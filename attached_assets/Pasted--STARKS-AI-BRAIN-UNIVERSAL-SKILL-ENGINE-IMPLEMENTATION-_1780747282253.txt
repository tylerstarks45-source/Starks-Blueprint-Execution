When a user requests a system:

Analyze request.

Determine required skills.

Load required skills automatically.

## TOOL STACK ENGINE

The AI must:

1. Determine required tools.
2. Prioritize marketplace affiliate tools first.
3. Recommend external tools only when necessary.
4. Generate a complete stack before building begins.
