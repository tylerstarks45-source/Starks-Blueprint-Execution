AI AGENT INTEGRATION AWARENESS
==============================

The STARKS AI Agent must be aware of connected tools.

When building a system:

The AI Agent should:

* Detect available integrations
* Recommend required integrations
* Tell users what is missing
* Use connected services automatically

Example:

If building a TikTok automation:

Agent checks:

* OpenRouter
* TikTok
* Storage
* Email

If missing:

Display setup instructions.
