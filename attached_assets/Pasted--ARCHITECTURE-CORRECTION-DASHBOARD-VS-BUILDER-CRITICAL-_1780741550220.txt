# ARCHITECTURE CORRECTION — DASHBOARD VS BUILDER

## CRITICAL PLATFORM RULE

The Dashboard and Builder are two separate products inside the platform.

Do NOT mix them together.

The current dashboard contains builder functionality that should not live there.

This must be refactored.

---

# DASHBOARD = COMMAND CENTER

Route:

/dashboard

Purpose:

Monitor and manage systems that already exist.

The Dashboard should NEVER be the place where users build systems.

The Dashboard is where users see:

* Uptime
* Downtime
* Activity

* Connected Tools

* AI Recommendations
