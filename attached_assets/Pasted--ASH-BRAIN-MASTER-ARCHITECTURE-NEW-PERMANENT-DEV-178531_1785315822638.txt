==================================================
PROJECT PHILOSOPHY
==================================================

ASH is NOT being rebuilt.

ASH is evolving.

The current implementation is the foundation of the platform.

The Master X-RAY remains the official baseline for every engineering decision.

Every future enhancement must follow the Upgrade Before Replace principle.

Order of preference:

1. Reuse existing architecture.
2. Extend existing architecture.
3. Refactor existing architecture.
4. Replace only when technically necessary.

No subsystem should ever be rewritten simply because a different implementation exists.
