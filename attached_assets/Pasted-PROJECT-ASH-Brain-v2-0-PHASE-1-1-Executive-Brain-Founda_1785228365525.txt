PROJECT: ASH Brain v2.0
PHASE: 1.1 - Executive Brain Foundation

IMPORTANT

Do NOT rebuild ASH.

Do NOT replace the existing AI Orchestrator.

Do NOT replace OpenRouter integration.

Do NOT replace the existing runtime.

Upgrade the existing architecture by adding a new Executive Brain layer that sits above the current orchestration pipeline.

----------------------------------------

GOALS

Create a new Executive Brain responsible for:

- Goal Management
- Decision Making
- Planning
- Task Prioritization
- Project Management
- Business State Tracking
- Execution Coordination

The Executive Brain should become the central controller for ASH while reusing the existing AI infrastructure.

----------------------------------------

RESPONSIBILITIES

The Executive Brain should:

1. Receive every user request before it reaches the orchestrator.

2. Determine the user's intent.

3. Determine if this belongs to an existing project or requires creating a new one.

4. Create or update objectives.

5. Break large requests into structured tasks.

6. Prioritize those tasks.

7. Decide which systems are required.

8. Pass execution to the existing AI pipeline.

----------------------------------------

PROJECT MANAGEMENT

Create a persistent Project object containing:

- Project ID

- Completed Tasks

GOAL MANAGEMENT

Each Goal should contain:

- Goal

- Completion Criteria

----------------------------------------

TASK MANAGEMENT

Create Task objects.

- Status

- Dependencies
