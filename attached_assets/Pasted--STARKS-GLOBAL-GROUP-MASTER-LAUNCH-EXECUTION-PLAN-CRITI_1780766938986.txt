# PHASE 1 — SECURITY LOCKDOWN

COMPLETE BEFORE ANY PUBLIC LAUNCH.

Fix every launch blocker identified in the audit.

### Protect User Routes

Secure:

* GET /api/users
* GET /api/users/:id
* PATCH /api/users/:id

Requirements:

* Require authentication
* Require ownership checks
* Require admin privileges for role changes
* Remove role modifications from non-admin updates

### Protect Admin Resources

Add requireAdmin middleware to:

* Blueprints
* Tools
* Tool Categories
* Blueprint Categories
* Affiliate Links

All create, update, and delete actions must be admin-only.

### Remove JWT Fallback Secret

Remove:

sbep-fallback-secret-change-in-prod

Platform must fail startup if SESSION_SECRET is missing.

### Verify Stripe Secrets

Verify:

* STRIPE_PRICE_BUILDER
* STRIPE_PRICE_OPERATOR
* STRIPE_PRICE_EMPIRE
* STRIPE_WEBHOOK_SECRET
