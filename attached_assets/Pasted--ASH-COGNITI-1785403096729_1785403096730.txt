PURPOSE
═══════════════════════════════════════════════════════════════════════

Build 008 gave ASH Goals.

Goals define the destination.

Build 009 gives ASH Planning.

Planning determines the optimal path from the current state toward a
goal without executing any actions.

The Executive Planning Engine becomes the permanent cognitive system
responsible for transforming goals into structured execution plans.

Planning is strategic thinking.

Execution comes later.

OBJECTIVES
═══════════════════════════════════════════════════════════════════════

Implement a reusable Planning Engine capable of:

• Building execution plans
• Breaking goals into milestones
• Creating ordered work steps
• Detecting dependencies
• Identifying blockers
• Estimating effort
• Estimating duration
• Supporting multiple alternative plans
• Ranking plans
• Recording planning history

Plans become permanent cognitive objects.
