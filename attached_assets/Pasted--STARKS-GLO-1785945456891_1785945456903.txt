PURPOSE
═══════════════════════════════════════════════════════════════════════

Create one canonical operating system responsible for every
external capability ASH can consume.

This build is NOT a collection of integrations.

This is the operating layer that discovers, installs,
authorizes, validates, monitors, optimizes, and governs
every external platform available to ASH.

ASH shall understand capabilities instead of products.

Stripe is not "Stripe."

Stripe provides:

• Payments

• Billing

• Invoicing

• Subscriptions

• Tax

• Connect

• Financial Reports

Those become individual capabilities.

System.

Everything outside the platform becomes discoverable,
classifiable, governable, monitorable, and reusable.

SPECIAL STRIPE REQUIREMENT
═══════════════════════════════════════════════════════════════════════

Before creating any Stripe adapter logic:

Inspect the existing platform.

Determine:

• What Stripe integration already exists.

• Which API version is in use.

• Which endpoints already function.

• Whether payments are live.

• Whether subscriptions exist.

• Whether invoices exist.

• Whether webhooks already exist.

• Whether Connect is implemented.

• Whether Billing is enabled.

• Whether Checkout is enabled.

NEVER duplicate existing Stripe functionality.

Instead:

Register the existing Stripe implementation inside UECIOS.

If gaps exist:

Record them.

Expose them as capabilities.

Do NOT rebuild working code.

CHIEF ARCHITECT NOTE

This build establishes the permanent operating system through
which ASH interacts with the outside world.

The first responsibility of this build is not to create new
integrations.

Its first responsibility is to understand what already exists,
reuse it wherever possible, eliminate duplication, and register
those capabilities inside the new operating system.

Only after that foundation exists should new providers be added.

When implementation is complete:

STOP.

Wait for Build 058.
