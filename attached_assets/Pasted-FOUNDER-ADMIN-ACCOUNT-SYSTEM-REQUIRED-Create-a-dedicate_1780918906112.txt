FOUNDER ADMIN ACCOUNT SYSTEM REQUIRED

Create a dedicated Founder/Admin account role for Tyler Starks.

This account must be separate from normal user accounts and have full platform administration capabilities.

========================================
FOUNDER ADMIN ROLE
==================

Create a role:

FOUNDER_ADMIN

This role should have unrestricted platform access while still using the same production systems that normal users use.

The goal is to test the platform exactly as customers experience it while maintaining full administrative control.

========================================
FOUNDER ACCOUNT PRIVILEGES
==========================

Founder Admin can:

* Access all pages
* Access all tools
* Access all blueprints
* Access all AI Agent modes
* Access all integrations
* Access all hosting features
* Access all monitoring features
* Access all subscription features
* Access all billing features

Founder account should never be blocked by plan limitations.

========================================
UNLIMITED TESTING MODE
======================

Founder account should have:

* Unlimited testing credits
* Unlimited AI Agent usage
* Unlimited blueprint builds
* Unlimited hosted systems
* Unlimited connections

However:

* Usage must still be tracked
* Usage must still appear in analytics
* Usage must still be logged

This allows real-world testing.
